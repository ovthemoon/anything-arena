# 아무거나 무기 배틀 — v0.2 변경 (플레이 방식 확정)

**작성일:** 2026-09-23. v0.1 기획서(`PRD_v0.1.md`)에 우선한다. 충돌하지 않는 항목은 v0.1 그대로.

## 핵심

**휴대폰 2대가 각자의 조종기, 컴퓨터 웹페이지가 공용 중계 화면이다.**

두 플레이어가 휴대폰으로 캐릭터와 무기를 만들고 공격을 입력하면, 컴퓨터 화면에서 전투 장면과 실시간 음성 중계를 함께 보는 파티 게임이다.

## 한 판의 흐름

1. 컴퓨터에서 방을 만들면 참가용 QR 코드와 방 번호가 표시된다.
2. 두 플레이어가 휴대폰 브라우저로 QR 또는 참가 링크에 접속한다. 방 번호로도 참가할 수 있다.
3. 각자 추천 캐릭터를 선택하거나 자유 입력으로 사람 캐릭터와 무기를 만든다.
4. 캐릭터·기술을 확인하고 준비 버튼을 누른다.
5. 두 명 모두 준비하면 컴퓨터에 VS 연출이 나오고 전투가 시작된다.
6. 휴대폰에서 공격을 입력하거나 기술 버튼을 누르면, 판정 결과와 피해량이 모든 화면에 반영된다.
7. 체력이 0이 되면 승패를 발표하고 재대결 또는 나가기를 선택한다.

## 기기별 화면

| 단계 | 휴대폰: 플레이어 화면 (`/play/:code`, 세로) | 컴퓨터: 공용 중계 화면 (`/screen/:code`, 가로 전체) |
|---|---|---|
| 입장 | 이름 입력, 방 참가 | 방 생성, QR 코드, 방 번호, 참가 현황 |
| 캐릭터 준비 | 추천 선택·직접 만들기, 무기 입력, 생성 결과 확인 | 참가한 캐릭터 소개, 준비 상태 |
| 대결 준비 | 준비 버튼, 상대 정보 | 두 캐릭터 VS 연출 |
| 전투 | 양쪽 체력, 작은 전투 미리보기, 큰 공격 입력창, 기술 버튼, 판정·대기 상태 | 큰 전투 장면, 체력바, 제한 시간, 타격 효과, 피해 숫자, 중계 자막·TTS |
| 결과 | 승패 확인, 재대결·나가기 | 승자 세리머니, 마지막 한 방, 재대결 준비 상태 |

단계별 별도 페이지 불필요. 대기실·전투 화면 안에서 상태 전환, 결과는 팝업 가능.

## 캐릭터와 비주얼

- 캐릭터는 **사람**이며, 설정이 황당한 무기·기술로 이어지는 재미가 핵심.
- 예: '순대국밥 20년차 욕쟁이 할머니'(국자·국물 회오리) vs '내 나이 15 이잼민'('응?' 키보드 방패).
- 비주얼: 한국 골목 배경의 코믹 웹툰풍 격투 게임. 큰 캐릭터, 과장된 표정, 강한 타격 효과.
- 컴퓨터 중계 화면에는 공격 입력창이 없다.
- 이미지 콘셉트·에셋은 별도 준비 중. 구현은 교체하기 쉬운 임시 에셋으로 진행.

## 기술 원칙

- Cloudflare Workers + Durable Objects + WebSocket.
- 같은 방에 플레이어 2명 + 공용 중계 화면(`SCREEN` 역할). 중계 화면은 좌석을 차지하지 않고 공격할 수 없다. 여러 대 연결 가능.
- 영상 전송이 아니라 서버가 상태·이벤트를 보내고 각 기기가 그린다.
- 체력·진행·공격 허용·피해량·승패는 서버가 확정. AI 는 해석·판정만, 피해량은 서버 고정 규칙.
- TTS·효과음은 기본적으로 **컴퓨터에서만** 재생. 중계 화면에 소리 켜기/끄기.
- 욕설·패드립·인신공격은 필터링하고 해당 휴대폰 입력창에서 경고.
- 공격 중복 제출 방지, 판정 중 상태 표시. AI·TTS 지연·실패로 경기가 멈추지 않는다.
- 재접속: 휴대폰 새로고침 → 같은 플레이어로 복귀(쿠키). 중계 화면 새로고침 → 현재 상태 복원(스냅샷).

## 계약 변경 (코드 반영 완료)

- `ConnectionRole = 'A' | 'B' | 'SCREEN'`; `room_snapshot.you` 가 이 타입.
- `POST /api/rooms` 는 컴퓨터가 호출, SCREEN 토큰 발급, 좌석 미배정. 응답 `{ roomCode, joinUrl }`.
- `POST /api/rooms/:code/join` 는 휴대폰이 호출, 빈 좌석(A→B) 배정, 같은 쿠키면 같은 좌석.
- `WeaponInput.character`(≤30), `WeaponProfile.characterName`, `PRESET_CHARACTERS` 추천 목록.
- `PublicMatchState.screenConnected`.

## 2시간 30분 MVP 우선순위

1. 휴대폰 2대 + 컴퓨터 1대에서 한 판 완주 (방 생성 → QR·코드 참가 → 임시 캐릭터 → 준비 → 고정 공격 → 체력 동기화 → 승패 → 재대결)
2. AI 캐릭터 생성
3. 자유 공격 의미 판정 + 입력 필터 + 서버 고정 피해
4. 전투 연출 (타격 모션, 피해 숫자, 화면 흔들림, 자막)
5. TTS (컴퓨터에서 재생)

제외: 회원가입, 랜덤 매칭, 랭킹, 캐릭터 영구 보관, 관전자 채팅.

**완료 기준: 두 사람이 휴대폰으로 플레이하고, 컴퓨터에서 같은 경기를 보며, 승패와 재대결까지 진행할 수 있는가.**
